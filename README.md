# Auto Coleta Mushyo 🚀

Este script foi desenvolvido para o Mushyo, um jogo de voice 🎮, com o objetivo de otimizar a coleta de itens dentro do jogo. Ele permite que o jogador interaja de forma automática com os objetos coletáveis, garantindo uma experiência mais fluida e eficiente.

# Funcionalidades ✨

Sistema de Coleta Automática 🛍️: O script permite que o jogador colete itens automaticamente ao se aproximar deles, sem a necessidade de interação manual constante.

Teleportação Automática 🌀: Quando um item coletável é encontrado, o script teleporta o jogador até o local do item para facilitar a coleta.

Pulo Automático 🤸: O jogador realizará o pulo automaticamente ao se aproximar de um item, evitando a perda de itens ou a necessidade de pular manualmente.

# Como Usar ⚙️

Ativar/Desativar o Script 🔄
Para ativar ou desativar o script, pressione a tecla G. Ao ativar, as funcionalidades de pulo automático e noclip (passar através de objetos) serão ativadas. Pressione novamente a tecla para desativar essas funções.

# Teclas de Atalho ⌨️

Coleta Automática 🛒: O sistema de coleta funciona automaticamente quando o script está ativado.

Pulo Automático 🦘: Ativado juntamente com o script, o pulo é executado automaticamente quando o jogador se aproxima de um item.
